# Daybook（desktop-todo）

**是什么**：Windows 桌面置顶小窗，记两类事——每日常规（一天内完成即可，可计时）+ 零碎待办，并留下完成记录。
**为什么做**：自用，提醒自己完成每日动作，零碎事项不丢。
**当前状态**：v0.4 可用（2026-11-03），基于 [flost8](https://github.com/singharyan006/flost8)（MIT）改造。

## 功能
- **每日常规**：每天 0 点自动重置，不把没做完的带到第二天（只进记录）。完成 = 绿色「通过」；过了晚间检查时间还没完成 = 红色「未完成」。
  - **计时型**：添加时在输入框右边填目标分钟数（或双击编辑）。▶ 开始 / ■ 停止，记录每段开始–结束时间；累计达标自动勾选并弹通知。同一时间只计一项；跨 0 点按 24:00 截断。
- **最近 7 天圆点**：绿 = 全部完成，红 = 有遗漏（悬停看漏了哪些），灰 = 无记录，空心 = 今天。
- **记录页**：选近 7 天 / 30 天 / 本月 / 全部或自定义日期，看常规完成率、全部完成天数、累计计时、待办完成数（按时率）、每项常规完成率，以及每天明细（绿通过 / 红未完成，计时项含分钟和时间段）。历史永久保留。
- **晚间检查**（默认 21:30，可在每日页修改）：到点还有没做完的 → 弹 Windows 系统通知，每天一次。
- **零碎待办**：点「+ 添加待办」填写表单——具体事项（必填）、计划时间、截止时间、截止提醒、重要/紧急（都可不选）。
  - 排序可切换：
    - **按时间**（默认）：先看截止时间，没有就看计划时间；按「已过期 / 今天 / 明天 / 后天 / 具体日期 / 未定时间」分组。
    - **按重要程度**：重要紧急 → 重要 → 紧急 → 其他，同组按截止时间。
  - 截止前 24h 内自动算紧急，过期标橙；时间都带周几，在列表里加粗显示。
  - 截止提醒：不提醒 / 截止时 / 提前 1h / 3h / 1 天，到点弹系统通知（填了截止时间默认提前 1h）。
  - 双击事项可编辑。
- **删除要确认**：点 ✕ 变成「确认删除」，3 秒内再点才删；「清除已完成」同样要点两次。
- **快捷键**：按 `?` 或点右上角键盘图标看全部；`Ctrl+Alt+D` 在任何地方呼出 / 隐藏。
- 配色：极简黑白 + 橙（#FF6A00），右上角切换深浅色。
- 右上角 ✕ = 隐藏到托盘（提醒继续工作）；托盘右键「退出」才真正退出。打包安装后开机自启。

## 运行（在 Windows 侧，不要在 WSL 里）
```cmd
cd /d D:\cc_workstation\workstation\projects\personal\desktop-todo
npm install        :: 慢的话先 set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
npm start          :: 开发运行
npm test           :: 跑每日逻辑测试
npm run build:win  :: 打包安装程序到 dist/
```

## 代码地图
- `src/renderer/services/dailyManager.js` — 计时 / 跨天重置 / 历史 / 检查提醒，纯函数，有测试
- `src/renderer/services/records.js` + `components/Records.js` — 记录页统计与渲染
- `src/renderer/app.js` — 状态、视图切换、每 30 秒 tick
- `src/main.js` — 窗口、托盘、系统通知（`notify` IPC）
- `src/renderer/services/todoSort.js` — 待办四象限排序 / 截止状态 / 截止提醒，纯函数，有测试
- `src/renderer/components/TodoForm.js` — 待办表单
- 样式全部在 `index.html` 的 `<style>`，颜色只用 `:root` 变量（已去掉 Tailwind）
- 调试：设置环境变量 `TODO_DATA_DIR` 指向独立目录，不污染真实数据

# Memo

**是什么**：Windows 桌面置顶小窗，记两类事——每日常规（一天内完成即可，可计时）+ 零碎待办，并留下完成记录。
**为什么做**：提醒自己完成每日动作，零碎事项不丢。
**名字**：项目统一叫 Memo / `memo`；本地数据目录仍是 `%APPDATA%/desktop-todo`（为了不丢数据，故意不改）。
**当前状态**：v1.6.1 可用。Windows 10 / 11 正式支持；Mac 是测试版（只在 GitHub 的 Mac 打包机上自动检查过，还没在真机上用过）。基于 [flost8](https://github.com/singharyan006/flost8)（MIT）改造。

## 下载安装
打开 [Releases](https://github.com/yihan498/memo/releases/latest)，按电脑下载：

**Windows**：下载 `Memo.exe`，双击安装。
- 安装程序没有做数字签名，Windows 可能弹出「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」
- 装好后 Memo 只在右下角托盘里（任务栏右下角「^」里也找一找），单击托盘图标或按 `Ctrl+Alt+D` 显示 / 隐藏；开机自动启动

**Mac（测试版）**：Apple 芯片（M1 及以后）下载 `Memo-arm64.dmg`，Intel 芯片下载 `Memo-x64.dmg`；打开后把 Memo 拖进「应用程序」。
- 没有苹果开发者签名，第一次打开会被拦住：先双击一次，再去「系统设置 → 隐私与安全性」，在下方点「仍要打开」
- 装好后 Memo 在屏幕右上角的菜单栏里，不占程序坞；按 `⌘⌥D` 显示 / 隐藏。界面上的 Ctrl 都换成 ⌘、Alt 换成 ⌥（切换页面的 Ctrl+Tab 仍是 ⌃Tab）

**更新**：每次打开 Memo（之后每 12 小时）会查一次有没有新版本。Windows 在后台自动下载，下好后弹通知，点通知立即重启更新，不点就在下次重启 Memo 时自动安装（Memo 常驻托盘，平时很少真正退出，建议点通知）；Mac 弹通知提醒，点开下载新的 dmg 覆盖安装。v1.6.0 之前装的版本没有这个功能，需要手动下载新版重装一次。

**数据**：只存在本机（Windows `%APPDATA%\desktop-todo`，Mac `~/Library/Application Support/desktop-todo`），卸载后保留，重新安装还在。除了访问 GitHub 检查更新（Windows 有新版本时会在后台下载约 70MB 的安装包），Memo 不联网、不上传任何数据。

## 功能
- **每日常规**：每天 0 点自动重置，不把没做完的带到第二天（只进记录）。完成 = 绿色「通过」；过了晚间检查时间还没完成 = 红色「未完成」。
  - **计时型**：添加时在输入框右边填目标分钟数（或双击编辑）。▶ 开始 / ■ 停止，记录每段开始–结束时间（列表里只显示「N 段」，悬停看各段时间；完整明细在记录页）。可以同时计好几项；跨 0 点按 24:00 截断。窗口收起时（`Ctrl+M`）按 `S` 直接停掉最近开始的那个计时，连按依次全停，不用先展开、也不管停在哪一页。两种：
    - **正计时**（默认）：显示已计时长，累计达标自动勾选并弹通知「已达标」，不停表。适合「至少做够 X 分钟」。
    - **倒计时**（分钟框左边点亮「倒」）：显示剩余时间，用完自动停表、勾选、弹通知「时间到」。适合「一天最多花 X 分钟」。结束时间按恰好用完那一刻记，电脑睡眠也不多记。
- **分区**：每日常规和零碎待办都可以填「分区」（如 产品 / 学习），同分区的事项框在一起，框头显示剩余数。顺序：还有没做完的分区（按名字）→ 未分区 → 已全部完成的分区（虚线框，沉到最底）；输入时会提示已有分区，也可以直接输入新名字。每日页在输入框中间填（填一次后保留，连续添加更顺手），待办在表单里填，双击可改。**框头的 + 可以直接在这个分区里添加**（每日页：回车即加、可连续加，Esc 收起；待办页：一句话回车 → 打开表单，分区已填好）。
- **最近 7 天圆点**：绿 = 全部完成，红 = 有遗漏（悬停看漏了哪些），灰 = 无记录，空心 = 今天。
- **记录页（月历）**：一个月一屏，‹ › 或 ← → 翻月，「今天」回到本月。每格：常规全部完成 = 绿底 ✓，有漏 = 红底 + 完成数，今天 = 橙色圆；下方小圆点是当天的待办（橙 截止 / 红 逾期 / 灰 计划 / 绿 完成）。点某天在下方看明细（每项常规、计时分钟和时间段、当天的待办），还能「+ 给这天添加待办」（预填计划时间为那天 09:00 + 到点提醒，时间可改）。最下面是本月统计：完成率、全部完成天数、累计计时、待办完成数（按时率）、每项常规完成率。历史永久保留。
- **晚间检查**（默认 21:30，可在每日页修改）：到点还有没做完的 → 弹 Windows 系统通知，每天一次。
- **一句话添加待办**：待办页底部直接输入一句话，回车后自动识别并打开填好的表单，核对后保存（输入框为空时点 + = 空白表单）。纯本地规则，不联网。
  - 例：`明天下午3点前把 bug 修完 #产品 重要 提前30分钟提醒` → 截止 明天 15:00、分区 产品、重要、提前 30 分钟提醒。
  - 能识别：`#分区`；重要 / 紧急；今天 明天 后天 今晚 明早、周五 下周一、11月8号 8号 11/8、月底 周末；下午3点 3点半 15:30；两小时后；提前X分钟/小时/天提醒、到点提醒、不提醒。
  - 带「前 / 之前 / 截止 / ddl」→ 截止时间（只写日期 = 当天 23:59，默认提前 1 小时提醒）；都没有 → 计划时间 =「这个点去做」（只写日期 = 9:00），默认到点提醒，「提前10分钟提醒」作用在计划时间上，「不提醒」关掉。没说上下午时 1–7 点按下午算。
  - 识别不了的原样留在事项文字里。规则在 `services/quickParse.js`，用例在 `tests/parse.test.mjs`——遇到识别错的句子，加进用例再改规则。
- **想法**（记录后面一页）：随手记小念头，底部写一句回车就存。任何地方按 `Ctrl+Alt+I` 呼出窗口并直接进入想法输入框。
  - **手机 → 电脑**：手机上照常发到微信「文件传输助手」；电脑微信里右键「复制」那条，按 `Ctrl+Alt+V`，剪贴板文字直接收进想法（不弹窗口，右下角通知；同样内容不重复收；不把 `#话题` 当分区）。一次收好几条：按 `Ctrl+Alt+Shift+V` 开收集模式，在微信里挨个右键「复制」，每条自动收进想法（不逐条弹通知）；再按一次结束，通知报总数；10 分钟没有新复制自动结束。微信没有开放接口、电脑微信多选后也不能复制，所以没做全自动拉取
  - **状态**：顶部切换「待处理 / 已落实 / 搁置」（带数量）。左边圆圈 = 标记已落实（再点改回）；悬停 ‖ = 搁置（暂时不做、舍不得删），在搁置页点 ↶ 恢复。落实 / 搁置会记下日期。
  - **分区**：输入框右边填分区（填一次后保留），或直接在句子里写 `#产品`。条目下显示分区标签，点标签 = 只看这个分区；右上角下拉框也能筛选。筛选某个分区时新记的想法自动归到这个分区。
  - 列表按天分组（今天 / 昨天 / 具体日期），新的在上。双击可改正文和分区；悬停 → 转成待办（带上分区，想法保留，做成了再点落实）、✕ 删除（点两次）。想法单独存，不参与提醒和记录页统计。
- **零碎待办**：表单字段——具体事项（必填）、计划时间 + 计划提醒、截止时间 + 截止提醒、重要/紧急（都可不选）。两种时间是两回事：计划 =「这个点去做」（很多事没有截止，只有时间点），截止 =「最晚什么时候」；各自的提醒只在填了对应时间时出现。
  - 排序可切换：
    - **按时间**（默认）：先看截止时间，没有就看计划时间；按「已过期 / 今天 / 明天 / 后天 / 具体日期 / 未定时间」分组。
    - **按重要程度**：重要紧急 → 重要 → 紧急 → 其他，同组按截止时间。
  - 截止前 24h 内自动算紧急，过期标橙；时间都带周几，在列表里加粗显示。
  - 计划提醒（🔔）：不提醒 / 到点 / 提前 10 分钟 / 30 分钟 / 1 小时，弹「该做了：xx」（填了计划时间默认到点提醒；错过超过 12 小时如关机期间就不补弹；v1.0 之前建的旧待办不会突然开始提醒）。
  - 截止提醒（⏰）：不提醒 / 截止时 / 提前 1h / 3h / 1 天，到点弹系统通知（填了截止时间默认提前 1h）。
  - 双击事项可编辑。
- **删除要确认**：点 ✕ 变成「确认删除」，3 秒内再点才删；「清除已完成」同样要点两次。
- **快捷键**：按 `?` 或点右上角键盘图标看全部；`Ctrl+Alt+D` 在任何地方呼出 / 隐藏。
- 配色：极简黑白 + 橙（#FF6A00），右上角切换深浅色。
- 只在托盘显示，任务栏没有图标：单击托盘图标 / `Ctrl+Alt+D` 显示或隐藏。托盘图标可能在任务栏右下角「^」里，可拖到常驻区。
- 右上角 ✕ = 隐藏到托盘（提醒继续工作）；托盘右键「退出」才真正退出。打包安装后开机自启。

## 开发
在 Windows 侧运行（不要在 WSL 里），需要 Node.js 20：
```cmd
npm install        :: 慢的话先 set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
npm start          :: 开发运行
npm test           :: 跑逻辑测试
npm run build:win  :: 打包安装程序到 dist/
```
发布新版本：改 `package.json` 的 version → 提交 → 推送同名标签（如 `git tag v1.6.1 && git push origin v1.6.1`），GitHub Actions 自动打包 Windows 安装程序和 Mac dmg 并发布到 Releases，已安装的 Memo 会自动发现（`src/updater.js`）。在 Actions 页面手动运行则只打包和自检：Mac 包会在 macOS 打包机上真的打开、截图，结果在 `mac-smoke` 里下载（`.github/scripts/smoke.sh`）。

- `src/renderer/services/todoSort.js` — 待办四象限排序 / 截止状态 / 截止提醒，纯函数，有测试
- `src/renderer/components/TodoForm.js` — 待办表单
- 样式全部在 `index.html` 的 `<style>`，颜色只用 `:root` 变量（已去掉 Tailwind）
- 调试：设置环境变量 `TODO_DATA_DIR` 指向独立目录（如项目下 `.testdata/`，已 gitignore），不污染真实数据；此时窗口显示不抢焦点。再设 `TODO_DEBUG_EVAL` 指向一个 js 文件，页面加载 1.5 秒后在渲染进程执行它（模拟输入 / 点击）
- 界面截图测试已封装成项目 skill：`.claude/skills/ui-check/`（一条命令完成：隔离数据 → 启动 → 模拟输入 → 定时截图 → 只关测试实例）。改完界面就跑一次，用法见其中的 SKILL.md
